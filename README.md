# WITRN 风扇统一控制台

一个**单文件网页工具**，统一控制 WITRN 维简智能小风扇的三个硬件版本，并内置固件升级。

```
W96D统一控制台.html  →  用 Chrome / Edge 打开即可，无需安装、无需服务器
```

- 工具版本 `v20260925h`（更新后请 `Ctrl+Shift+R` 强刷）
- 固件升级已在真机验证通过
- 协议、抓包与测试见 [`W96D协议与技术文档.md`](W96D协议与技术文档.md)

---

## 功能

| 版本 | 连接方式 | 能做什么 |
|---|---|---|
| **老版 W96D**（USB 线） | WebHID | 档位、转速、自然风曲线（组×点×周期）、遥测 |
| **NEW W96D**（蓝牙） | Web Bluetooth | 开关、档位/转速、定时、Turbo、灯光、蓝牙休眠、减档模式、档位标定、自然风曲线、版本/SN、电池与状态 |
| **W96D Pro**（蓝牙 + 快充） | Web Bluetooth | 上面全部 + 快充协议实验（⚠ 高风险） |
| 全部 | — | 统一通信日志、固件升级（NEW W96D / Pro） |

- **风扇控制**：开关、四档切换、无级转速、定时关机、Turbo、灯光、按键减档行为、各档风速标定。
- **自然风曲线**：画布上直接画出风量变化、设定一圈时长后上传，设备按曲线自动变速；可恢复默认。
- **设备信息**：固件版本、序列号、电池电压/电流/容量、输入电压、电机状态；可让蓝牙名带上 SN 便于区分多台设备。
- **固件升级**：选择 `.up` 固件后一键升级，带进度与结果判读（见下）。
- **通信日志**：所有连接方式的收发原始数据都记录在页面底部，可切换是否记录高频遥测。

## 快速开始

1. 用 **Chrome / Edge** 打开 `W96D统一控制台.html`（iOS / Safari 不支持 Web Bluetooth）；
2. 按版本点连接按钮，并在**页面弹出的列表**里选设备（不要用系统蓝牙界面配对）：

   | 版本 | 按钮 | 选哪个 |
   |---|---|---|
   | NEW W96D / W96D Pro | 连接蓝牙 | `W96D…` / `W96P…` |
   | 老版 W96D | 连接HID | `DeepFan`（安卓需先在 `chrome://flags` 开 `web-hid-on-android`） |

3. 连接成功后即可操作；固件升级在**设备信息页**。

## 固件升级

设备信息页 → 固件升级 → 选择固件（如 `rom/W96D_V13.up`）→ 开始升级。

> ⚠ 升级过程中请保持供电、不要断电或关闭页面。若中途失败，设备会停在升级模式，重新连接后再升一次即可。
> 首个 `0x88` 无应答属正常（设备在写入最后几页并校验），工具会自动重试；若提示"写入未被接受"，把「写入间隔」调到 30~40ms 再升一次。

流程与失败判读详见 [技术文档第 5 节](W96D协议与技术文档.md)。
